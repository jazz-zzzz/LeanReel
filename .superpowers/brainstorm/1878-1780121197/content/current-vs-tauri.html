LeanReel 当前架构 vs Tauri 重构

理解现状，看清重构的代价和收益

当前：PySide6 (Qt Widgets)
🖥️ Python 3.11+
GUI 层
QMainWindow / QSplitter
QTableView + 自定义 Model
QTreeWidget / QDockWidget
QSS 样式表（暗色主题）
⚠ QPropertyAnimation 仅用于展开收起
业务层
Controllers / Services
SQLite / FFmpeg 子进程
打包
PyInstaller → Windows .exe
Tauri 方案
🦀 Rust + Web 前端
GUI 层
WebView2（系统 WebView）
HTML/CSS/JS 任意前端框架
CSS 动画 / Web Animations API
✓ 完整的 Web 动画能力
业务层
Rust 命令（Tauri Commands）
SQLite / FFmpeg 子进程
打包
Tauri Bundler → 更小的 .msi/.exe

动效能力对比

PySide6 (Qt)

  • QPropertyAnimation — 仅能动画 Qt 属性
  • 无 CSS transition/animation
  • 无 keyframe 动画系统
  • 自定义动画代码量大、难维护
  • 微交互几乎不可行

Tauri (Web)

  • CSS transitions / animations 全覆盖
  • Web Animations API（JS 控制）
  • 丰富的第三方动效库可选
  • 声明式动画，代码量少
  • 微交互、转场、骨架屏均可实现

关键权衡因素

维度 PySide6 Tauri
动效能力 受限 完整
重写工作量 无 极大（全部重写）
FFmpeg 集成 直接 subprocess Rust Command::new
打包体积 ~80MB+ (含 Python 运行时) ~5-15MB (不含 WebView2)
