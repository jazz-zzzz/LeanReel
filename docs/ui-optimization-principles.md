# LeanReel UI 优化依据

日期：2026-05-15

## 假设

LeanReel 是一个高密度桌面生产工具。用户的核心任务是批量判断媒体文件是否值得处理，而不是观看影片、欣赏封面或探索内容。

默认产品边界已经确定：HEVC/H.265、HDR10、HDR10+ 和 Dolby Vision 都是优质片源，默认完全不处理。UI 必须围绕这个边界建立可见、可查、可测试的交互规则。

## 限制

- 当前 UI 使用 PySide6 和集中式 QSS，不引入 Web 前端、SVG 插画或复杂动效。
- 当前信息架构是三栏主界面：库面板、文件列表、策略面板，底部队列面板。
- 当前内置策略由 JSON 定义，UI 应尊重技术策略名，不再使用含糊营销名。
- 当前文档先约束设计依据，不直接替代代码实现。

## 可衡量成功标准

1. 用户能在文件列表中直接看出哪些文件被跳过，以及为什么跳过。
2. `全选` 不会选中 HEVC/HDR/Dolby Vision 等优质片源。
3. 策略名能直接表达编码器、格式、质量参数和用途，例如 `NVENC HEVC CQ 26 快速转码`。
4. 主界面保持高密度扫描能力，不因为装饰性卡片降低每屏文件量。
5. 每个关键状态同时有文字或图标，不只靠颜色。
6. UI 改动可以映射到 `PRODUCT.md` 和 `DESIGN.md` 中的原则。

## 推荐优化方向

### 1. 文件列表优先

文件列表是产品主舞台。后续 UI 优化应优先服务表格可读性、排序、筛选、选择和风险解释。

建议：
- 将“匹配策略”列改名为“处理建议”，因为它既可能是策略，也可能是跳过原因。
- 对跳过行使用禁用勾选框，加蓝色信息文本，不使用红色或警告黄。
- 在文件名列或策略列增加 tooltip，说明跳过依据。
- 让“待处理 / 已跳过 / 已完成”筛选真正工作，避免成为装饰控件。

### 2. 策略面板技术化

策略面板不再展示“轻量、均衡、极限”。策略行应展示技术名和关键参数，描述单独显示。

建议：
- 保持紧凑单选行。
- 策略描述只显示当前选中项。
- CPU/GPU/COPY 标签固定位置，降低扫描成本。
- `CRF`、`CQ`、`NV 预设`必须提供 tooltip。
- 自定义区只在用户明确选择“自定义”时展开。

### 3. 优质片源保护

保护规则应该是 UI 的一等公民，而不是后台逻辑。

建议：
- 跳过原因使用固定文案：
  - `跳过：HEVC/H.265 片源`
  - `跳过：HDR10 片源`
  - `跳过：HDR10+ 片源`
  - `跳过：Dolby Vision 片源`
- 状态栏在用户勾选全选后可以显示“已自动排除 N 个优质片源”。
- 不提供默认快捷入口去处理这些片源。未来如果增加强制处理，应放入高级设置并二次确认。

### 4. 队列面板更像操作日志

队列面板应回答：当前在做什么，完成了多少，失败了什么，节省了多少。

建议：
- 总进度文本继续显示完成、跳过、失败、取消。
- 任务行按状态显示图标、文件名、阶段和体积变化。
- 失败行显示短错误，完整日志放 tooltip 或详情入口。
- `清空已完成` 不应清空正在运行或失败待处理项，后续可拆成更明确按钮。

### 5. 色彩和状态

当前暖暗色方向适合长时间桌面使用，可以保留。优化重点是减少装饰性使用，让颜色表达状态。

建议：
- Amber 只用于主操作、焦点、选中和进度。
- Blue 用于跳过和信息状态。
- Green 用于完成。
- Red 用于失败和不可恢复错误。
- Yellow 用于高风险设置和调试开关。

## 边缘情况与风险

- 长策略名可能挤压下拉框和表格列，需要列宽、tooltip 和截断策略。
- 中文、英文和技术缩写混排时，过窄控件容易误读 CRF/CQ。
- 禁用跳过行后，用户可能疑惑为什么不能选，需要 tooltip 和状态栏解释。
- 深色界面对低对比灰字敏感，辅助文字不能低于当前 `#8a857c` 的可读水平。
- 如果未来增加强制处理 HEVC/HDR 的高级模式，必须和默认安全策略视觉隔离。

## 内部四视角评估

建造者：文档把 UI 改动落到现有 PySide6/QSS 架构，不要求一次性重构。

评论者：最大风险是视觉优化变成装饰升级。文档明确把文件列表和优质片源保护放在第一优先级。

测试者：可测点包括禁用勾选、全选过滤、跳过文案、策略名、筛选行为、列宽和状态色。

性能视角：高密度表格和底部队列比大卡片更适合批量处理，能减少滚动和误操作。

## 验证指标

- UI 单测：跳过行不可勾选，全选不会选中跳过行。
- UI 单测：策略名完整显示或通过 tooltip 可读。
- 视觉检查：900x600 最小窗口不出现关键按钮遮挡。
- 视觉检查：1400x900 默认窗口能同时看到库、文件列表、策略和状态栏。
- 可用性检查：用户能在 5 秒内说出一个文件为什么被跳过。
- 可用性检查：用户能区分选中行和勾选待处理。

## 置信度

置信度：0.88。

主要未确定因素：用户是否更偏好更现代的浅色生产力界面；是否需要为大屏 NAS 管理场景提供更宽的表格布局；是否希望未来支持“高级强制处理优质片源”的独立视觉路径。
