# LeanReel 用户行为规范 v1.0

> 本文档从**用户视角**描述每个功能的行为。不涉及代码、API、类名。任何实现必须以本文档为唯一真相来源。

---

## A. 核心数据规则

### A1. 文件信息来源
- 文件列表**总是**反映磁盘当前状态 + 数据库缓存。
- 文件被用户从磁盘删除后，重建缓存时**自然消失**（不再出现于列表）。
- 文件被重命名后，旧条目消失，新条目出现并重新探测。
- 文件内容没变时（大小和修改时间都一致），**不需要重新探测编码**，直接复用已有数据。
- 文件内容变了（大小或修改时间变了），**必须重新探测编码**。

### A2. 缓存可信条件
- 以下五项**全部齐全**才认为缓存可信，可以直接复用：编码格式、文件大小、分辨率宽度、分辨率高度、探测成功标记。
- 缺任何一项 → 视为不可信 → 必须重新探测。

### A3. 数据显示优先级
- 文件体积：**磁盘实际大小**优先。如果探测工具返回的体积不准确或为 0，用磁盘实际大小覆盖。
- 其他数据（编码、分辨率、HDR 类型、音轨、字幕）：**探测工具返回值**。

## B. 文件列表（平铺视图）

### B1. 列
用户看到的列按从左到右：

| 列名 | 内容 |
|------|------|
| 勾选框 | 可勾选的显示勾选框，不可勾选的显示禁用勾选框 |
| 文件名 | 文件的基本名称（不含目录路径） |
| 体积 | 人类可读的文件大小（如 `1.5 GB`） |
| 编码信息 | 编码格式 + 分辨率（如 `h264 1920x1080`）。探测中显示"探测中…"。探测失败显示"探测失败"。无编码信息显示"未识别" |
| HDR | HDR 类型（SDR / HDR10 / HDR10+ / Dolby Vision） |
| 处理策略 | 当前将应用的策略名称。受保护的文件显示跳过原因（如"跳过：HEVC/H.265 片源"）。探测失败的文件显示"探测失败"。未匹配的文件显示"未匹配" |
| 预计结果 | 压缩后的预计节省空间或状态（如"35-50%"、"不处理"、"无法估算"、"—"） |

### B2. 勾选框
- 可以被处理的文件：勾选框**可用**，用户可以勾选/取消。
- 受保护的文件（HEVC、HDR10、HDR10+、Dolby Vision）：勾选框**禁用**，不可勾选。悬停时显示跳过原因。
- 探测失败的文件：勾选框**禁用**。
- "全选"按钮**只勾选**可处理的文件。受保护的和探测失败的不会被选中。
- "取消全选"按钮清除所有勾选。
- 状态栏显示"已选中 N/M 个可处理文件"，N=实际勾选数，M=可处理的文件总数。

### B3. QComboBox 策略下拉
- 列 5（处理策略）**始终显示一个下拉框**（不需要双击才出现）。
- 下拉框包含所有预设策略 + "自定义"选项。
- 用户选择策略时，**立即生效**，列 6（预计结果）同步更新。
- 鼠标在策略列上滚动滚轮时，**不改变策略**——滚轮事件穿透到表格滚动。
- 选择"自定义"时，右侧策略面板切换到自定义模式。

### B4. 颜色标记
- 编码信息列：绿色 = 探测成功，红色 = 探测失败，灰色 = 其他。
- HDR 列：蓝色 = Dolby Vision，金色 = HDR10/HDR10+，灰色 = SDR。
- 处理策略列：蓝色 = 受保护跳过，红色 = 探测失败。

### B5. 过滤
用户可以通过顶部下拉框筛选显示的文件：

| 选项 | 显示 |
|------|------|
| 全部 | 所有文件 |
| 可处理 | 勾选框可用的文件 |
| 已保护跳过 | HEVC / HDR / DV 等自动跳过的文件 |
| 探测失败 | 探测出错的文件 |
| 已选择 | 当前已勾选的文件 |

### B6. 排序
- 用户点击列标题可以进行升序/降序排列。
- 体积和预计结果按**数值**排序（不是按文本排序——`9 GB` 排在 `100 MB` 前面）。
- 探测进行期间**不自动排序**（避免行位置跳动）。探测完成后用户可以手动排序。

### B7. 探测过程中的表现
- 添加文件夹后，文件列表**立即出现**（先显示占位信息，如"探测中…"）。
- 随着探测进行，每一行的编码信息、HDR、处理策略、预计结果**逐个出现**——而不是一次性全部刷出。
- 用户可以在这个过程中**正常滚动、勾选、切换视图**。
- 状态栏显示当前探测进度（如"探测中：42/500 …"）。
- 全部探测完成后，状态栏显示"编码信息探测完成"，表格排序功能启用。

## C. 树视图（目录树）

### C1. 视图切换
- 用户可以通过顶部下拉框在"平铺"和"目录树"之间切换。
- 切换时**勾选状态保持不变**——在平铺视图中勾选的文件，切到树视图后仍然勾选，反之亦然。

### C2. 树结构
- 文件按目录分组显示。
- 每个文件夹节点显示文件夹名称和**该文件夹内所有文件的总大小**。
- 文件夹节点加粗显示。

### C3. 树视图功能
- 勾选框：与平铺视图的行为完全相同（可处理的可勾选，受保护的禁用）。
- 颜色：与平铺视图完全一致。
- 文件夹右键菜单 → "重建此文件夹缓存" → 只重新扫描该文件夹。
- 点击文件夹节点上的体积列可以按总大小排序。

### C4. 探测更新
- 探测过程中切换到树视图，已探测完成的行**正常显示**，未探测的显示占位信息。
- 探测继续在后台进行，树视图中的行也**实时更新**。

## D. 重建缓存（刷新）

### D1. "重建缓存"按钮
- 点击"重建缓存"：**立即清空当前列表**，状态栏显示"扫描中…"。
- 几秒内（取决于文件数量），列表重新出现，源文件不变的文件**保留已有数据**。
- 文件变更、新增、删除的情况按照 A1 规则处理。
- 探测完成后状态栏显示"编码信息探测完成"。

### D2. 单文件夹重建
- 左侧库面板：右键文件夹 → "重建缓存" → 只重新扫描该文件夹。
- 树视图：右键文件夹 → "重建此文件夹缓存" → 只重新扫描该文件夹。

### D3. 重复点击防护
- 如果重建缓存已在进行中，再次点击会提示"扫描已在进行中，请等待完成"。

### D4. 错误恢复
- 如果网络断开导致扫描失败，状态栏显示"扫描失败，请检查网络连接后重试"。
- 如果扫描找到 0 个文件，状态栏显示"未找到视频文件"。

## E. 策略与编码

### E1. 策略面板
- 右侧策略面板显示当前所有预设策略。
- **选中列表中的一行**：策略面板自动显示该文件当前应用的策略。
- **选中多行**：策略面板不绑定特定文件。
- 用户在策略面板中切换策略时，**所有已勾选的文件**同步应用新策略。
- 用户选择"自定义"时，策略面板展开自定义参数（编码器、CRF/CQ、NVENC 预设、音轨处理、字幕处理）。

### E2. 编码
- 用户勾选文件 → 点击"开始编码" → 文件加入底部队列。
- 队列中每个任务显示文件名、当前策略、进度、状态。
- 不同文件夹中同名文件在队列中不会混淆。
- 用户可以暂停、取消编码。
- 输出文件采用**原子替换**——旧输出不会被半成品覆盖。如果替换失败，旧文件保持不变。

## F. 性能与体验

### F1. 响应性
- 无论文件数量多少，**用户始终可以拖动窗口、滚动列表、点击按钮**——不出现"界面卡死"。
- 列表首次出现时间应在点击操作后 0.5 秒内。
- 切换到已有库时，列表**立即显示**（不出现长时间空白）。

### F2. 大数据量
- 支持 1000+ 个文件的文件夹而不卡顿。
- 支持多文件夹（跨多个 NAS 路径）同时使用。

### F3. NAS 网络
- 在网络正常的情况下，1000 个文件的完整探测应在 1-2 分钟内完成。
- 单个文件的编码探测约 0.1-0.2 秒。

## G. 错误处理

| 场景 | 用户看到 |
|------|---------|
| 文件探测失败 | 显示"探测失败"，列 3 悬停有错误详情 |
| 数据库写入失败 | 静默重试 3 次，仍失败则该文件列为"探测失败" |
| 网络断连 | 显示"探测失败"或"扫描失败" |
| 重复添加相同文件夹 | 提示该文件夹已存在 |
| 重复点击重建 | 提示"扫描已在进行中" |
| 应用关闭时正在编码 | 编码任务被取消 |

## H. 完整验收清单

操作以下步骤，逐条确认通过/不通过：

- [ ] 1. 启动应用 → 无 Qt 警告/错误
- [ ] 2. 新建库 → 添加文件夹 → 文件列表出现，占位信息逐行变为真实数据
- [ ] 3. 列 5 始终显示下拉框（不需双击才能看到）
- [ ] 4. 鼠标在列 5 滚动 → 策略不变，表格滚动
- [ ] 5. 下拉框切换策略 → 预计结果同步变化
- [ ] 6. 全选：只勾选可处理的文件
- [ ] 7. 过滤 "可处理" → 只显示可处理的文件
- [ ] 8. 过滤 "已保护跳过" → 只显示受保护的文件
- [ ] 9. 过滤 "已选择" → 只显示勾选的文件
- [ ] 10. 切到树视图 → 文件夹大小显示，颜色与平铺一致
- [ ] 11. 树勾选文件 → 切回平铺 → 勾选保持
- [ ] 12. 选中一行 → 右侧策略面板同步
- [ ] 13. 多选 → 切换策略 → 所有选中文件应用
- [ ] 14. 探测完成后点"重建缓存" → 旧数据不消失 → 流式更新
- [ ] 15. 右键文件夹重建 → 只刷新单个文件夹
- [ ] 16. 切库 → 列表马上出现（<1 秒）
- [ ] 17. 编码流程：勾选 → 开始 → 队列正常工作
- [ ] 18. 探测过程中可以正常滚动、切换视图
- [ ] 19. 拖动窗口过程中可以正常操作
- [ ] 20. 退出应用 → 无崩溃、无残留进程
